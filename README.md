# WATERMARK REMOVER

Application web locale destinée à nettoyer la marque visible de créations Gemini autorisées.

## État

Version v0.1 en cours de développement.

## Principes

- traitement entièrement local dans le navigateur ;
- aucun téléversement des images ;
- fichier original préservé ;
- SynthID et les marqueurs invisibles ne sont pas supprimés.
